WHAT THESE SIGNALS MEAN

A window into the network.
Not the whole internet.

Cloudflare Radar aggregates observations from Cloudflare’s network and published event feeds. This dashboard is a saved, dated view of those measurements. It cannot show all networks, all traffic, or all outages.

Normalized traffic is a relative index, not a request count or country ranking. IP versions use percentage units. Missing points are gaps, never zeroes. Outage descriptions and causes are source reports, not conclusions inferred from the traffic chart.

The website does not ask for an API token. A scheduled collector retrieves source data separately; your browser loads the resulting public snapshot. Follow source links for current context.
